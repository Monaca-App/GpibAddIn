# コマンドリファレンス：Judge

## 概要
`Judge` は、計測データと閾値（リミット値）の大小・一致関係を各種比較演算子（符号）に基づいて評価し、判定結果が不成立（規格外・NG）となった場合のみ、指定されたステップ番号へ制御をジャンプ（条件分岐）させる実行フロー・条件分岐系コマンドです。
製品検査における「合否判定（リミットチェック）」や、規定値に達するまで測定を繰り返す「上限/下限監視ループ」の構築に活用します。

> 💡 **補足 / ⚠️ 注意**
> 本コマンドは、2つの数値を浮動小数点数（`double`）として精密にパースして比較を行います。評価した結果が「合格（成立）」であれば、ジャンプせずに次のステップへ進み、「不合格（不成立）」となった場合にのみジャンプがトリガーされます。

---

## 💡 書式・パラメータ仕様

```csv
,SEQUENCE, [ステップキー], Judge, [判定符号], [比較値1(計測値)], [比較値2(閾値)], [ジャンプ先ラベル名]
```

### パラメータ（引数）一覧

| 引数位置 | 引数名 | 説明 | 指定方法 / 有効な入力値 |
| :--- | :--- | :--- | :--- |
| **引数1** | 判定符号 | 比較に使用する演算子。大文字・小文字不問。 | `GE`, `GT`, `LE`, `LT`, `EQU`（詳細は後述） |
| **引数2** | 比較値1（計測値） | 判定対象となる動的なデータや計測値。 | 固定値、またはパラメータ動的置換（例: `$V_MEAS$`） |
| **引数3** | 比較値2（閾値） | 合否の境界となるリミット値（基準値）。 | 固定値（例: `5.5`）またはパラメータ動的置換（例: `$P_LIMIT$`） |
| **引数4** | ジャンプ先ラベル名 | 判定失敗（NG）の際に遷移する `SEQUENCE` のジャンプ先ラベル名（ステップキー）。 | ジャンプ記法（例: `#10#` や `#Error#`）またはラベル名（例: `10` や `Error`）。省略時はマクロ終了。 |

### 💡 判定符号（引数1）の詳細仕様

| 指定符号 | 判定条件（成立＝合格、不成立＝NGジャンプ） | 意味 |
| :--- | :--- | :--- |
| **GE** | 比較値1 ≥ 比較値2 | 比較値1が比較値2以上なら合格 |
| **GT** | 比較値1 > 比較値2 | 比較値1が比較値2より大きいなら合格 |
| **LE** | 比較値1 ≤ 比較値2 | 比較値1が比較値2以下なら合格 |
| **LT** | 比較値1 < 比較値2 | 比較値1が比較値2より小さいなら合格 |
| **EQU** | 比較値1 = 比較値2 | 比較値1と比較値2が等しいなら合格 |

## 🔄 特殊置換規約・分岐規約の適用

本コマンドの引数における、独自スクリプトの特殊記法の適用ルールです。

*   **動的置換（`$`）**: 引数2および引数3において、`$PARAMキー$` のようにパラメータキーの両端を `$` で囲むことで、実行時に変数プール（`PARAM`）の値へと動的にパース展開・値置換されます。
*   **条件ジャンプ（`#`）**: 引数4において、ターゲットとなるラベル名を `#10#` や `#Error#` のように `#` で囲んで指定することで、合否判定NG時のジャンプ先として安全にバインドされます。
*   **カンマのエスケープ**: 比較値文字列や閾値パラメータにカンマを含める場合は、構文エラーを防ぐため必ず `","` と二重引用符で囲んで記述する必要があります。

## 💡 動作例（正しい構文での記述例）

### スクリプト記述例
> ⚠️ **記述ルール注意**
> COMMANDブロック配下のため、子要素行（`PARAM`, `SEQUENCE`）は必ず行頭カンマから開始し、スペースインデントや行末コメント（`;`）は記述しないでください。コメントを入れる場合は、必ず独立したコメント行（行頭 `;`）を前に挟んでください。

```csv
COMMAND, "Voltage_Limit_Test"
; コメントは独立した行に記述（行末への記述は完全禁止）
,PARAM, V_MEAS, Value, "実測電圧", "0.0"
; 1. 電圧の測定と値の回収
,SEQUENCE, 10, Send, "MEAS:VOLT?"
,SEQUENCE, 20, Receive
,SEQUENCE, 30, SetData, $V_MEAS$, "%s"
; 2. 下限チェック: 実測電圧(V_MEAS)が 4.75(閾値)「以上(GE)」でなければ、エラー処理(#50#)へ
,SEQUENCE, 40, Judge, GE, $V_MEAS$, 4.75, #60#
; 3. 上限チェック: 実測電圧(V_MEAS)が 5.25(閾値)「以下(LE)」でなければ、エラー処理(#50#)へ
,SEQUENCE, 50, Judge, LE, $V_MEAS$, 5.25, #60#
; 4. 正常系: 上下限をクリアしたため、マクロを正常終了
,SEQUENCE, 55, Exit
; 5. 異常系: 規格外エラー処理
,SEQUENCE, 60, Send, "OUTP OFF"
```

### 実行時の挙動・変数変化

*   **実行前の状態**: 測定コマンドによって取得された実測値が変数 `V_MEAS` に格納（例: `"4.50"`, 不合格範囲）されており、合否リミットが定義されている状態です。
*   **実行後の状態**: 変数 `V_MEAS` の値が `double` 型へ内部展開され、下限閾値（`4.75`）と比較評価されます。`4.50` は `4.75` 未満であり、「GE（以上）」の条件を満たさないため不成立（NG）と判定され、実行フローは引数4で指定されたステップキー `#60#` へと安全にジャンプ（条件分岐）します。

## 🚫 エラーハンドリング・安全設計（仕様制限）

入力データの異常や記述ミスに対し、解析・実行エンジンが実行するセーフティ規約です。

*   **数値変換に失敗した場合（double.TryParse）**
    引数2や引数3にアルファベットなどの非数値文字が混入してパースに失敗した場合、内部ログにエラーを書き込み、メモリ破損や予期せぬ挙動を防ぐために即座にマクロの末尾へ安全に処理を遷移（マクロ終了）させます。
*   **未定義の演算符号が指定された場合（HandleUnknownSign）**
    引数1に `=>` や `==` など、規定以外の未定義符号が指定された場合、システムは安全を最優先して判定結果を「強制不成立（NG）」として扱い、ログに警告を出力した上で安全にジャンプまたは終了シーケンスへ誘導します。
*   **ジャンプ先パラメータ（引数4）に不備がある場合**
    引数4が省略されている場合、または指定されたラベル名がマクロ内に存在しない場合は、エラーログを記録した上で現在のマクロの末尾へ安全に処理を遷移（正常終了）させ、不正アクセスやハングアップを完全に遮断します。

## 🧪 ユニットテスト仕様

本コマンドクラスに実装されている `RunUnitTest()` メソッドが検証するユニットテストの仕様です。

### テスト実行前提条件
* **実行トリガー**: `RunUnitTest()` メソッドの呼び出し
* **有効化条件**: システム全体の最小ログレベル（`ErrorLogger.MinimumLevel`）が `LogLevel.Test` であること（それ以外の場合は無効化ガードにより即座に早期リターン）
* **検証結果出力**: `ErrorLogger.LogTest` によるログ出力。検証失敗時は `ErrorLogger.LogError`、予期せぬ例外発生時は `ErrorLogger.LogCritical` で記録

### テストケース一覧

| No | テストカテゴリ | テスト条件（入力値） | 期待される結果（出力値） | 検証の目的 / 観点 |
| :--- | :--- | :--- | :--- | :--- |
| **1** | 正常系 | `sign = "GE"`<br>比較 1: `val1 = 5.5`, `val2 = 3.0`<br>比較 2: `val1 = 2.0`, `val2 = 3.0` | 比較 1 戻り値: `true`<br>比較 2 戻り値: `false`<br>エラーメッセージ: `null` | 「大なりイコール（GE）」判定において、比較条件の成立（以上）および不成立（未満）が正しく評価されること。 |
| **2** | 正常系 | `sign = "EQU"`<br>比較 1: `val1 = 3.14`, `val2 = 3.14`<br>比較 2: `val1 = 3.14`, `val2 = 3.15` | 比較 1 戻り値: `true`<br>比較 2 戻り値: `false`<br>エラーメッセージ: `null` | 「等価（EQU）」判定において、値が完全に一致する場合と異なる場合が正しく評価されること。 |
| **3** | 異常系 | `sign = "INVALID"`<br>`val1 = 1.0`, `val2 = 1.0` | 戻り値: `false`<br>エラーメッセージが返されること | 未定義の判定演算子が指定された場合に評価が失敗し、エラーメッセージが生成されること。 |
