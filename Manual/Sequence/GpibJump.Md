# コマンドリファレンス：Jump

## 概要
`Jump` は、現在の測定状態や条件に関わらず、指定されたステップ番号へシーケンスの実行ポインタを無条件に遷移（ジャンプ）させるための実行フロー・条件分岐系コマンドです [1.1]。
マクロ内での「特定の処理ブロックの繰り返し（無限ループの形成）」や、「エラー処理・終了処理ブロックへの一方向強制遷移」などを実装する際に使用します [1.1]。

> 💡 **補足 / ⚠️ 注意**
> 本コマンドは条件判定を挟まずにマクロの実行順序を強制的に変更します [1.1]。コマンドが実行されると、ジャンプフラグ（`param.Jump`）が即座に `true` に設定され、指定のステップ番号へ制御が移ります [1.1]。

---

## 💡 書式・パラメータ仕様

```csv
,SEQUENCE, [ステップキー], Jump, [ジャンプ先ラベル名]
```

### パラメータ（引数）一覧

| 引数位置 | 引数名 | 説明 | 指定方法 / 有効な入力値 |
| :--- | :--- | :--- | :--- |
| **引数1** | ジャンプ先ラベル名 | 条件なしで強制遷移させる `SEQUENCE` のジャンプ先ラベル名（ステップキー） [1.1]。 | ジャンプ記法（例: `#10#` や `#Start#`）またはラベル名（例: `10` や `Start`） [1.1]。 |

---

## 🔄 特殊置換規約・分岐規約の適用

本コマンドの引数における、独自スクリプトの特殊記法の適用ルールです [1.1]。

*   **動的置換（`$`）**: 引数1において、`$PARAMキー$` のようにパラメータキーの両端を `$` で囲むことで、実行時に変数プール（`PARAM`）の値へと動的にパース展開・値置換されます [1.1]。
*   **条件ジャンプ（`#`）**: 引数1において、ターゲットとなるラベル名を `#10#` や `#Start#` のように `#` で囲んで指定することで、無条件のジャンプ先として安全にバインドされます [1.1]。
*   **カンマのエスケープ**: 本コマンドの引数はラベル名およびステップキー指定を想定しているため、カンマのエスケープ規約は原則適用されません。

## 💡 動作例（正しい構文での記述例）

### スクリプト記述例
> ⚠️ **記述ルール注意**
> COMMANDブロック配下のため、子要素行（`PARAM`, `SEQUENCE`）は必ず行頭カンマから開始し、スペースインデントや行末コメント（`;`）は記述しないでください [1.1, 1.2]。コメントを入れる場合は、必ず独立したコメント行（行頭 `;`）を前に挟んでください [1.1]。

```csv
COMMAND, "Continuous_Data_Loop"
; コメントは独立した行に記述（行末への記述は完全禁止）
,PARAM, P_BUF, Work, "一時バッファ", ""
; 1. 計測器にトリガーを送信してデータを回収
,SEQUENCE, 10, Send, "INIT;FETCH?"
,SEQUENCE, 20, Receive
,SEQUENCE, 30, SetData, P_BUF, "%s"
; 2. 任意の追加処理（省略）
; 3. 【無条件ジャンプ】ステップ10へ強制的に戻る（無限ループの形成）
,SEQUENCE, 40, Jump, #10#
; 4. ループを明示的に終了させたい場合は、存在しないラベル名（例: 「0」）を指定することでマクロを安全に早期終了可能
,SEQUENCE, 50, Exit
```

### 実行時の挙動・変数変化

*   **実行前の状態**: 連続サンプリングルーチン等において、一連の測定コマンド送信およびデータ回収（ステップ10〜30）が完了したコンテキストです [1.2]。
*   **実行後の状態**: `Jump` コマンドが評価されると、条件判定を経ずに即座に引数1で指定されたステップキー `#10#` へと実行フローが安全にジャンプ（ループ）します [1.1, 1.2]。これにより、指定ブロックの繰り返し処理が実現されます [1.1]。

## 🚫 エラーハンドリング・安全設計（仕様制限）

入力データの異常や記述ミスに対し、解析・実行エンジンが実行するセーフティ規約です [1.2]。

*   **ジャンプ先（引数1）の未指定ガード**
    引数1が省略、または `null` の場合、内部ログにエラー（`LogError`）を書き込み、予期せぬ動作を防止するために即座にマクロの末尾へ安全に処理を遷移（マクロ終了）させます [1.2]。
*   **存在しないラベル名（ステップキー）が指定された場合**
    指定されたラベル名（または数値）が現在のマクロ内に存在しない場合、システムはこれを実行フローの終了（アボート）とみなします。エラーでシステムが停止するのを防ぐため、自動的にマクロの末尾へ安全に処理を進めて終了させます [1.2]。
