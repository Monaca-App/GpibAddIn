# コマンドリファレンス：Array_Init

## 概要
`Array_Init` は、指定されたX軸（列）およびY軸（行）の要素数と区切り文字（デリミタ）に基づいて、Work型変数向けのテキストベース二次元配列バッファを高速に初期化生成する配列バッファ操作系コマンドです。
主に、これ以降の自動化ステップで計測器から連続して取得するデータ（データグリッド）を受け止めるためのメモリ領域を、あらかじめ一括確保・初期設定しておく用途に使用します。

> 💡 **補足 / ⚠️ 注意**
> 指定された格納先変数にすでにデータが存在する場合、既存データはすべて破棄され、新しい空の二次元バッファで完全に上書きされます。

---

## 💡 書式・パラメータ仕様

```csv
,SEQUENCE, [ステップキー], Array_Init, [格納先変数], [X軸要素数], [Y軸要素数], [区切り文字]
```

### パラメータ（引数）一覧

| 引数位置 | 引数名 | 説明 | 指定方法 / 有効な入力値 |
| :--- | :--- | :--- | :--- |
| **引数1** | 格納先変数 | 生成された二次元バッファ（テキスト）を代入する変数名。 | `PARAM` であらかじめ定義した `Work` 型の変数キー名 |
| **引数2** | X軸要素数 | 横方向のデータセル数（列数）。1以上の整数。 | 固定値（例: `3`）またはパラメータ動的置換（例: `$P_COLS$`） |
| **引数3** | Y軸要素数 | 縦方向のデータ行数（行数）。1以上の整数。 | 固定値（例: `5`）またはパラメータ動的置換（例: `$P_ROWS$`） |
| **引数4** | 区切り文字 | 要素（セル）同士を区切るためのデリミタ文字列。 | カンマを指定する場合は必ず `","` で囲む。\t（タブ）や \n（改行）などのエスケープ展開処理は行われません。区切り文字にタブ文字やスペースを使用する場合は、マクロファイル内に直接タブ文字やスペースを入力し、二重引用符で囲んで記述してください（例: "[タブ文字]" ）。半角スペースは `" "` と入力します。 |

---

## 🔄 特殊置換規約・分岐規約の適用

本コマンドの引数における、独自スクリプトの特殊記法の適用ルールです。

*   **動的置換（`$`）**: 引数内で `$PARAMキー$` のようにパラメータキーの両端を `$` で囲むと、実行時に `PARAM` の値へと動的置換されます。（適用可能な引数：引数2、引数3、引数4）
*   **条件ジャンプ（`#`）**: 本コマンドはジャンプ処理を行わないため、引数内での `#` によるステップキー指定は使用しません。
*   **カンマのエスケープ**: 引数自体にカンマを含める場合は、構文エラーを防ぐため必ず `","` と二重引用符で囲んで記述する必要があります。

## 💡 動作例（正しい構文での記述例）

### スクリプト記述例
> ⚠️ **記述ルール注意**
> COMMANDブロック配下のため、子要素行（`PARAM`, `SEQUENCE`）は必ず行頭カンマから開始し、スペースインデントや行末コメント（`;`）は記述しないでください。コメントを入れる場合は、必ず独立したコメント行（行頭 `;`）を前に挟んでください。

```csv
COMMAND, "Measure_Setup"
; データ格納用のワークエリアを定義
,PARAM, CH1_RAW, Work, "データ格納用"
; 3列×4行の配列をカンマ区切りで初期化（カンマは引用符で囲む）
,SEQUENCE, 10, Array_Init, CH1_RAW, 3, 4, ","
```

### 実行時の挙動・変数変化

*   **実行前の状態**: `PARAM` 宣言により、変数プールに `CH1_RAW` が確保された状態です。
*   **実行後の状態**: 変数 `CH1_RAW` に、3列×4行のカンマ区切り空配列テキストが格納されます。3列の場合、各行内のカンマ数は2個となり、各行の境界に行区切りの改行（CRLF）が挿入されます（※最終行の末尾には改行コードは付与されません）。
    ```text
    ,,
    ,,
    ,,
    ,,
    ```

## 🚫 エラーハンドリング・安全設計（仕様制限）

入力データの異常や記述ミスに対し、解析・実行エンジンが実行するセーフティ規約です。

*   **非数値や0以下の数値が入力された場合**
    X軸・Y軸要素数に非数値や 0 以下の数値が指定された場合は、内部で安全に早期リターン（該当ステップをスキップ）し、バッファ生成を行いません。これによりメインシステムがフリーズするのを防ぎます。
*   **存在しない格納先キーが指定された場合**
    引数1で指定された変数名が、あらかじめ定義された変数プール（`PARAM`）に存在しない場合、エラーログを出力して処理を安全に中断し、システム全体の強制終了（例外発生）を自動防御します。

## 🧪 ユニットテスト仕様

本コマンドクラスに実装されている `RunUnitTest()` メソッドが検証するユニットテストの仕様です。

### テスト実行前提条件
* **実行トリガー**: `RunUnitTest()` メソッドの呼び出し
* **有効化条件**: システム全体の最小ログレベル（`ErrorLogger.MinimumLevel`）が `LogLevel.Test` であること（それ以外の場合は無効化ガードにより即座に早期リターン）
* **検証結果出力**: `ErrorLogger.LogTest` によるログ出力。検証失敗時は `ErrorLogger.LogError`、予期せぬ例外発生時は `ErrorLogger.LogCritical` で記録

| No | テストカテゴリ | テスト条件（入力値） | 期待される結果（出力値） | 検証の目的 / 観点 |
| :--- | :--- | :--- | :--- | :--- |
| **1** | 正常系 | `xCount = 3`<br>`yCount = 2`<br>`delimiter = ","` | `,,`（改行）`,,` | 複数行・複数列の二次元配列が、指定されたデリミタと改行で正しく初期化されること。 |
| **2** | 異常系/境界値 | `xCount = 0`<br>`yCount = 3`<br>`delimiter = ","` | `""`（空文字列） | 列数（X）が0以下の場合、安全に早期リターンされ、空文字列が返されること。 |
