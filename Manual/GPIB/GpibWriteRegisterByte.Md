# コマンドリファレンス：WriteRegisterByte

## 概要
`WriteRegisterByte` は、Interface製ボードの物理レジスタに対して直接バイトデータを書き込む 物理層・デバイス制御系 コマンドです。
ボード上の制御用オフセットアドレスに対して直接制御データを書き込むことにより、低レベルなハードウェア設定を動的に変更する目的で使用されます。

## 💡 書式・パラメータ仕様
```csv
,SEQUENCE, [ステップキー], WriteRegisterByte, [ボードID], [オフセット], [書き込み値]
```

### パラメータ（引数）一覧

| 引数位置 | 引数名 | 説明 | 指定方法 / 有効な入力値 |
| :--- | :--- | :--- | :--- |
| 引数1 | ボードID | 対象とするGPIBボードの識別ID番号。 | 固定値（整数）、PARAM変数キー、動的置換が可能です。 |
| 引数2 | オフセット | 書き込み対象 of レジスタのオフセットアドレス。 | 10進数または16進数（例: 0x04）、PARAM変数キー、動的置換が可能です。 |
| 引数3 | 書き込み値 | レジスタに直接書き込むバイト値（0〜255）。 | 10進数または16進数（例: 0xFF）、PARAM変数キー、動的置換が可能です。 |

## 🔄 特殊置換規約・分岐規約の適用
本コマンドの引数における、独自スクリプトの特殊記法の適用ルールです。
*   **動的置換（`$`）**: 引数内で `$PARAMキー$` のように記述すると、実行時に変数プール（PARAM）の値へ動的置換されます。（適用可能な引数：引数1、引数2、引数3）
*   **ジャンプ先指定（`#`）**: 本コマンドは分岐制御を行わないため、ジャンプ先指定は適用されません。
*   **共通コマンド指定（`@`）**: 外部マクロ名や機器を対象としないため、共通コマンド指定は適用されません。
*   **カンマのエスケープ**: 引数自体にカンマを含める場合は、必ず `","` と二重引用符で囲んで記述します。

## 💡 動作例（正しい構文での記述例）
### スクリプト記述例
※COMMANDブロック配下のため、子要素行（PARAM, SEQUENCE）は必ず行頭カンマから開始し、スペースインデントや行末コメント（`;`）は記述しないでください。

```csv
COMMAND, "WriteRegSample", ""
,PARAM, @BOARD_ID, Value, "ボード番号", "0"
,PARAM, @OFFSET, Value, "レジスタオフセット", "0x04"
,PARAM, @DATA, Value, "書き込み値", "0xAA"
,SEQUENCE, S001, WriteRegisterByte, $@BOARD_ID$, $@OFFSET$, $@DATA$
```

### 実行時の挙動・変数変化
*   **実行前の状態**: `@BOARD_ID` の値は `0`、`@OFFSET` の値は `0x04`、`@DATA` の値は `0xAA`。
*   **実行後の状態**: ボードID `0` のオフセットアドレス `0x04` の物理レジスタにバイトデータ `0xAA` が直接書き込まれます。変数バッファ（PARAM）の値は変化しません。

## 🚫 エラーハンドリング・安全設計（仕様制限）
入力データの異常や記述ミスに対し、解析・実行エンジンが実行するセーフティ規約です。
*   **非対応のドライバーがロードされている状態での呼び出し（仕様制限）**  
    本コマンドは Interface製ドライバー（`GPC4304.DLL`）専用の機能です。CONTEC製ドライバー（`CGPIB.DLL`）がロードされている動作環境で本コマンドが実行された場合、実行エンジンは「専用機能使用不可」の警告ログを出力し、物理層への通信を行わずに安全に早期正常終了（スキップ）してシステムフリーズを防ぎます。
*   **書き込み値の範囲外インデックスチェック**
    引数3（書き込み値）に 0 未満または 255 を超える整数（またはバイト表現ではない数値）が指定された場合、エラーログを出力して書き込み処理を実行せずにスキップし、システム動作の安全を保証します。
*   **引数パラメータのパースエラー**
    引数2（オフセット）に数値として解析できない文字列（"ERROR" など）が指定された場合、値は `0` として処理され、強制終了を回避します。
