# コマンドリファレンス：WaitAsyncTransfer

## 概要
`WaitAsyncTransfer` は、先行して開始された非同期データ転送の完了を待機し、受信結果（実際の転送サイズおよび受信データ文字列）を取得する 物理層・デバイス制御系 コマンドです。
`StartAsyncTransfer` によって開始された非同期受信が完了するのをタイムアウト時間まで監視し、回収したデータをPARAM変数に格納すると同時に、使用済み転送バッファをメモリから安全に解放します。

## 💡 書式・パラメータ仕様
```csv
,SEQUENCE, [ステップキー], WaitAsyncTransfer, [ボードID], [転送ID], [タイムアウト], [結果サイズ格納変数キー], [受信データ格納変数キー]
```

### パラメータ（引数）一覧

| 引数位置 | 引数名 | 説明 | 指定方法 / 有効な入力値 |
| :--- | :--- | :--- | :--- |
| 引数1 | ボードID | 対象とするGPIBボードの識別ID番号。 | 固定値（整数）、PARAM変数キー、動的置換が可能です。 |
| 引数2 | 転送ID | `StartAsyncTransfer` から返された非同期転送ID。 | 整数、PARAM変数キー、動的置換が可能です。 |
| 引数3 | タイムアウト | 転送完了を待機する最大許容時間（ミリ秒）。 | 0 以上の整数、PARAM変数キー、動的置換が可能です。 |
| 引数4 | 結果サイズ格納変数キー | 実際に転送された受信バイト数を格納する変数のキー名。 | `@` で始まるPARAM変数キー（例: `@ACT_SIZE`）を直接指定します。 |
| 引数5 | 受信データ格納変数キー | 【任意】受信データをASCII文字列にデコードして格納する変数のキー名。 | `@` で始まるPARAM変数キー（例: `@REC_STR`）を直接指定します。省略可能です。 |

## 🔄 特殊置換規約・分岐規約の適用
本コマンドの引数における、独自スクリプトの特殊記法の適用ルールです。
*   **動的置換（`$`）**: 引数内で `$PARAMキー$` のように記述すると、実行時に変数プール（PARAM）の値へ動的置換されます。（適用可能な引数：引数1、引数2、引数3、引数4、引数5）
*   **ジャンプ先指定（`#`）**: 本コマンドは分岐制御を行わないため、ジャンプ先指定は適用されません。
*   **共通コマンド指定（`@`）**: 外部マクロ名や機器を対象としないため、共通コマンド指定は適用されません。
*   **カンマのエスケープ**: 引数自体にカンマを含める場合は、必ず `","` と二重引用符で囲んで記述します。

## 💡 動作例（正しい構文での記述例）
### スクリプト記述例
※COMMANDブロック配下のため、子要素行（PARAM, SEQUENCE）は必ず行頭カンマから開始し、スペースインデントや行末コメント（`;`）は記述しないでください。

```csv
COMMAND, "AsyncReceiveSample", ""
,PARAM, @BOARD_ID, Value, "ボード番号", "0"
,PARAM, @TRANS_ID, Value, "転送ID", "9999"
,PARAM, @TMO, Value, "タイムアウト値", "5000"
,PARAM, @ACT_SIZE, Value, "受信サイズ", "0"
,PARAM, @REC_STR, Value, "受信テキスト", ""
,SEQUENCE, S002, WaitAsyncTransfer, $@BOARD_ID$, $@TRANS_ID$, $@TMO$, @ACT_SIZE, @REC_STR
```

### 実行時の挙動・変数変化
*   **実行前の状態**: `@BOARD_ID` の値は `0`、`@TRANS_ID` の値は `9999`、`@TMO` の値は `5000`、`@ACT_SIZE` の値は `0`、`@REC_STR` の値は空文字列。
*   **実行後の状態**: 非同期転送の完了が待機され、受信したデータサイズ（例: `32`）が `@ACT_SIZE` に格納され、受信した生データが文字列（例: `"MEASURED_DATA_OK"`）にデコードされて `@REC_STR` に格納されます。また、使用済みのバッファメモリは安全に解放されます。

## 🚫 エラーハンドリング・安全設計（仕様制限）
入力データの異常や記述ミスに対し、解析・実行エンジンが実行するセーフティ規約です。
*   **非対応のドライバーがロードされている状態での呼び出し（仕様制限）**  
    本コマンドは Interface製ドライバー（`GPC4304.DLL`）専用の機能です。CONTEC製ドライバー（`CGPIB.DLL`）がロードされている動作環境で本コマンドが実行された場合、実行エンジンは「専用機能使用不可」の警告ログを出力し、物理層への通信を行わずに安全に早期正常終了（スキップ）してシステムフリーズを防ぎます。
*   **存在しない転送IDを指定した場合のエラーハンドリング**
    指定された `transferId` に対応するバッファがプール内に存在しない場合（すでに解放されている、あるいは開始されなかった等）、実行エンジンは安全のために物理API呼び出しを行わず、エラーログを記録して早期リターンを行い、不正ポインタアクセスを自動防御します。
*   **タイムアウト時間の無効値の指定**
    引数3（タイムアウト時間）に 0 未満の負数が指定された場合、エラーログを出力し、待機処理を実行せずに即時リターンします。
