# コマンドリファレンス：Call

## 概要
`Call` は、事前に登録された外部マクロ（サブルーチン）に対して、任意の個数の引数（キーと値のペア）を一括代入し、対象マクロを安全に呼び出して同期実行するための実行フロー・条件分岐系コマンドです。
共通の計測ルーチンなどをモジュール化して呼び出すことで、効率的なスクリプト開発が可能になります。

> 💡 **補足 / ⚠️ 注意**
> 内部で非同期処理（Async）の完了待機（`GetAwaiter().GetResult()`）が管理されているため、サブルーチン処理中におけるエディタのフリーズや、実行完了前に次のステップへ進行するデッドロック現象を完全に防止します。

---

## 💡 書式・パラメータ仕様

```csv
,SEQUENCE, [ステップキー], Call, [呼び出し先マクロ名], [引数キー1], [値1], [引数キー2], [値2]...
```

### パラメータ（引数）一覧

マクロスクリプトからは、最初の呼び出し先マクロ名に続けて、任意の数だけ [引数キー] と [値] のペアを連続して指定できます。

| 引数位置 | 引数名 | 説明 | 指定方法 / 有効な入力値 |
| :--- | :--- | :--- | :--- |
| **引数1** | 呼び出し先マクロ名 | 呼び出すターゲットマクロ（`COMMAND`）の名前。<br>先頭に `@` を指定すると共通コマンド（`GENERAL`）を対象とし、`@` を付けない場合は現在の機器に対するマクロを対象とします。 | 固定文字列（例: `"Sub_Measure"`、`"@Common_Measure"`） |
| **引数2** | 引数キー1 | 呼び出し先マクロに定義されている変数（`PARAM`）のキー名。 | 固定キー文字列（例: `"CH_NO"`） |
| **引数3** | 値1 | 引数キー1に引き渡す具体的なデータ。変数置換に対応。 | 固定値（例: `100`）またはパラメータ動的置換（例: `$P_VAL$`） |
| **引数4〜** | 可変長引数ペア | 必要に応じて、以降 [キー] [値] のペアを連続して配置可能。 | 引数2・引数3の規則に準じる |

---

## 🔄 特殊置換規約・分岐規約の適用

本コマンドの引数における、独自スクリプトの特殊記法の適用ルールです。

*   **共通コマンド指定（`@`）**: 呼び出し先マクロ名の先頭に `@` を付与することで、呼び出し元の機器（デバイス）に関わらず、共通コマンド（`GENERAL`）として定義されているマクロを呼び出し対象とすることができます。`@` を付けない場合は、現在の機器に対するマクロが対象となります。（例：`"@Sub_Measure"`）
*   **動的置換（`$`）**: 引数に指定する「値」の位置（引数3、引数5など）においては、`$PARAMキー$` のようにパラメータキーの両端を `$` で囲むことで、実行時に変数プールの値へと動的にパース展開されます。これにより、呼び出し元のマクロが保持しているユーザー入力値をサブルーチンへと安全に引き継ぐことが可能です。
*   **条件ジャンプ（`#`）**: 本コマンドはジャンプ処理を行わないため、引数内での `#` によるステップキー指定は使用しません。
*   **カンマのエスケープ**: 可変長パラメータの各境界となるカンマと区別するため、引数内にカンマを含む文字列を値として渡す場合は、必ず `","` と二重引用符で囲んで記述する必要があります。

## 💡 動作例（正しい構文での記述例）

### スクリプト記述例
> ⚠️ **記述ルール注意**
> COMMANDブロック配下のため、子要素行（`PARAM`, `SEQUENCE`）は必ず行頭カンマから開始し、スペースインデントや行末コメント（`;`）は記述しないでください。コメントを入れる場合は、必ず独立したコメント行（行頭 `;`）を前に挟んでください。

```csv
# ======================================================================
# 呼び出される側のマクロ（共通モジュール）
# ======================================================================
COMMAND, "Sub_Measure"
,PARAM, CH_NO, Value, "対象CH", "1"
,PARAM, V_MAX, Value, "上限閾値", "5.0"
,SEQUENCE, 10, Send, "SELECT_CH 1"
,SEQUENCE, 20, Receive
# ======================================================================
# 呼び出す側のメインマクロ
# ======================================================================
COMMAND, "Main_Process"
,PARAM, P_CH, Value, "設定CH", "5"
; 固定値で CH_NO="2", V_MAX="3.5" を渡してサブルーチンを実行
,SEQUENCE, 10, Call, "Sub_Measure", "CH_NO", "2", "V_MAX", "3.5"
; 呼び出し元の変数 P_CH の値を、サブルーチンの変数 CH_NO へ引き継いで実行
,SEQUENCE, 20, Call, "Sub_Measure", "CH_NO", "$P_CH$", "V_MAX", "10.0"
```

### 実行時の挙動・変数変化

*   **実行前の状態**: 共通モジュール（`Sub_Measure`）がシステムに登録されており、呼び出す側のメインマクロで引き渡し用の変数（`P_CH` = `"5"`）が準備されている状態です。
*   **実行後の状態**: `Call` コマンドによってターゲットマクロがキックされます。可変長ペアで並べたパラメータが自動的に相手側の変数プールへ同期・格納された上で、サブルーチンが同期実行されます。サブルーチンが完全に終了するまでメインマクロの次ステップ進行は安全に待機（ブロック）されます。

## 🚫 エラーハンドリング・安全設計（仕様制限）

入力データの異常や記述ミスに対し、解析・実行エンジンが実行するセーフティ規約です。

*   **呼び出し先マクロ（引数1）がシステムに存在しない場合**
    指定されたマクロ名が見つからない場合、内部ログにエラー（`LogError`）を出力し、不正なマクロ遷移によるシステムハングを防ぐためにサブルーチンを実行せずに処理を安全にアボート（即時終了）します。後続の処理は安全にスキップされます。
*   **指定した引数キーが相手側に存在しない場合**
    呼び出し先マクロに存在しない変数キー（例: `P99`）を指定した場合、ログに警告（`LogWarning`）を記録した上で、メモリ破壊を防ぐために該当する値の代入処理だけを安全にスキップし、マクロ自体の呼び出し実行はそのまま続行します。
*   **引数のペアが不完全（奇数個）な場合**
    [キー] に対する [値] が不足している不完全な記述がある場合、算出ロジック（`(Count - 1) / 2`）によって端数の不完全ペアは自動的に無視（スキップ）され、型安全を維持して実行を継続します。

## 🧪 ユニットテスト仕様

本コマンドクラスに実装されている `RunUnitTest()` メソッドが検証するユニットテストの仕様です。

### テスト実行前提条件
* **実行トリガー**: `RunUnitTest()` メソッドの呼び出し
* **有効化条件**: システム全体の最小ログレベル（`ErrorLogger.MinimumLevel`）が `LogLevel.Test` であること（それ以外の場合は無効化ガードにより即座に早期リターン）
* **検証結果出力**: `ErrorLogger.LogTest` によるログ出力。検証失敗時は `ErrorLogger.LogError`、予期せぬ例外発生時は `ErrorLogger.LogCritical` で記録

| :--- | :--- | :--- | :--- | :--- |
| **1** | 正常系 | `paramsDict = { "@ARG1": "0", "@ARG2": "init" }`<br>`key = "ARG1"`<br>`value = "123.4"` | 戻り値: `true`<br>`paramsDict["@ARG1"]`の値が `"123.4"` に更新される | 存在する変数キーに対して値が正しくバインド（上書き代入）されること。 |
