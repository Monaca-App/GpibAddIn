# コマンドリファレンス：Div

## 概要
`Div` は、指定された別のコマンドマスタ（サブルーチンや外部マクロ等）が保持する変数（`PARAM`）群に対し、複数の指定キーと除算値をペア単位で動的に一括除算（割り算）する制御系シーケンスコマンドです。
実数演算における重大なエラーとなる「0除算（Divide by Zero）」に対する強力な防御レイヤーを備えています。

> 💡 **補足 / ⚠️ 注意**
> 加算コマンド（`Add`）と同様に、元の変数が持っていた文字列表記形式（整数、固定小数点、科学技術用指数表記など）を自動で解析して追従・整形するインテリジェントなフォーマット復元機能を内蔵しています。
> 例えば、元の現在値が `"1.000"`（固定小数点3桁：F3）であれば除算後も `"0.500"` となり、`"1.24E+3"`（指数表記：E）であれば `"6.2000E+02"` のように元の表記の美しさ・データ形式を破壊せずに維持・適用します。

---

## 💡 書式・パラメータ仕様

```csv
,SEQUENCE, [ステップキー], Div, [対象マクロ名], [変数キー1], [除算値1], [変数キー2], [除算値2]...
```

### パラメータ（引数）一覧

マクロスクリプトからは、最初の対象マクロ名に続けて、任意の個数（可変長）だけ [変数キー] と [除算値] のペアを連続して指定できます。

| 引数位置 | 引数名 | 説明 | 指定方法 / 有効な入力値 |
| :--- | :--- | :--- | :--- |
| **引数1** | 対象マクロ名 | 変数群を書き換える対象のターゲットマクロ（`COMMAND`）の名前。<br>先頭に `@` を指定すると共通コマンド（`GENERAL`）を対象とし、`@` を付けない場合は現在の機器に対するマクロを対象とします。 | 固定文字列（例: `"Sub_Measure"`、`"@Common_Measure"`）※変数置換対応 |
| **引数2** | 変数キー1 | 対象マクロ内に定義されている1つ目の変更先変数名。 | `PARAM` で定義されたキー名（例: `"CURR_SET"`）※変数置換対応 |
| **引数3** | 除算値1 | 変数キー1を割りたい数値（`0` は指定不可）。 | 固定値（例: `2` や `10.0`）またはパラメータ動的置換（例: `$P_DIV$`） |
| **引数4〜** | 可変長引数ペア | 任意の個数（可変長）だけペアを並べて一括除算可能。 | 引数2・引数3の規則に準じる |

## 🔄 特殊置換規約・分岐規約の適用

本コマンドの引数における、独自スクリプトの特殊記法の適用ルールです。

*   **共通コマンド指定（`@`）**: 対象マクロ名の先頭に `@` を付与することで、自身が属する機器（デバイス）に関わらず、共通コマンド（`GENERAL`）として定義されているマクロのパラメータを対象とすることができます。`@` を付けない場合は、現在の機器に対するマクロが対象となります。（例：`"@Sub_Measure"`）
*   **動的置換（`$`）**: すべての引数において、`$PARAMキー$` のようにパラメータキーの両端を `$` で囲むことで、実行時に変数プール（`PARAM`）の値へと動的にパース展開・値置換されます。
*   **条件ジャンプ（`#`）**: 本コマンドはジャンプ処理を行わないため、引数内での `#` によるステップキー指定は使用しません。
*   **カンマのエスケープ**: 可変長パラメータの各境界となるカンマと区別するため、対象マクロ名等にカンマを含む文字列を指定する場合は、必ず `","` と二重引用符で囲んで記述する必要があります。

## 💡 動作例（正しい構文での記述例）

### スクリプト記述例
> ⚠️ **記述ルール注意**
> COMMANDブロック配下のため、子要素行（`PARAM`, `SEQUENCE`）は必ず行頭カンマから開始し、スペースインデントや行末コメント（`;`）は記述しないでください。コメントを入れる場合は、必ず独立したコメント行（行頭 `;`）を前に挟んでください。

```csv
# ======================================================================
# 呼び出される側のマクロ（共通モジュール：Sub_Measure）
# ======================================================================
COMMAND, "Sub_Measure"
,PARAM, CURR_SET, Value, "印加電流", "1.000"
,SEQUENCE, 10, Send, "SOUR:CURR 1"
# ======================================================================
# 呼び出す側のメインマクロ（減衰スイープ制御ループ）
# ======================================================================
COMMAND, "Main_Div_Process"
; 1. 共通マクロを呼び出して、現在の電流値で計測を実行
,SEQUENCE, 10, Call, "Sub_Measure"
; 2. 【一括除算】Sub_Measure の印加電流(CURR_SET)を「2」で割る（毎回半減させる）
; ※元の "1.000" という表記から固定小数点3桁(F3)が自動検知され、結果は "0.500" の桁数で維持されます
,SEQUENCE, 20, Div, "Sub_Measure", "CURR_SET", "2"
; 3. 必要な回数だけステップ10へ戻ってループ
,SEQUENCE, 30, Jump, #10#
```

### 実行時の挙動・変数変化

*   **実行前の状態**: ターゲットとなる共通マクロ（`Sub_Measure`）の変数 `CURR_SET` が `"1.000"` の文字列状態で保持されている状態です。
*   **実行後の状態**: `Div` コマンドが実行されると、現在のマクロから指定された他のマクロ内の変数プールを直接指定し、安全に除算処理が実行されます。数値のパースおよび文字列化には不変カルチャ（`CultureInfo.InvariantCulture`）が適用され、実数の小数点（ピリオド）が正確に処理され、変数キー `CURR_SET` は自動フォーマット復元により `"0.500"` へと同期更新されます。

## 🚫 エラーハンドリング・安全設計（仕様制限）

入力データの異常や記述ミスに対し、解析・実行エンジンが実行するセーフティ規約です。

*   **0除算（除算値 == 0.0）を検知した場合**
    指定された除算値が `0` の場合、システムエラーでクラッシュさせずに内部ログ（`LogError`）を出力し、該当する変数ペアの演算だけを安全にスキップして後続のペア処理を続行します。
*   **対象マクロ名（引数1）が見つからない場合**
    指定されたマクロ名がシステム内に登録されておらず、パラメータ辞書の取得に失敗した場合は、内部ログを出力して除算処理を即座に安全にアボート（処理中断）します。
*   **非数値の検出時**
    「元の現在値」や「指定された除算値」が `double.TryParse` で数値変換できない文字列であった場合は、エラーログを排出した上で該当する変数ペアの演算だけを安全にスキップします。
*   **演算結果が不正値（NaN/Infinity）になった場合の保護**
    除算結果が計算の限界を超えて `NaN`（非数）や `Infinity`（無限大）に陥ったことを検知した場合、値の上書きによるバッファ汚染を防ぐため、値を上書きせずにログ（`LogError`）を記録して処理を安全に弾きます。

## 🧪 ユニットテスト仕様

本コマンドクラスに実装されている `RunUnitTest()` メソッドが検証するユニットテストの仕様です。

### テスト実行前提条件
* **実行トリガー**: `RunUnitTest()` メソッドの呼び出し
* **有効化条件**: システム全体の最小ログレベル（`ErrorLogger.MinimumLevel`）が `LogLevel.Test` であること（それ以外の場合は無効化ガードにより即座に早期リターン）
* **検証結果出力**: `ErrorLogger.LogTest` によるログ出力。検証失敗時は `ErrorLogger.LogError`、予期せぬ例外発生時は `ErrorLogger.LogCritical` で記録

### テストケース一覧

| No | テストカテゴリ | テスト条件（入力値） | 期待される結果（出力値） | 検証の目的 / 観点 |
| :--- | :--- | :--- | :--- | :--- |
| **1** | 正常系 | `currentRawVal = "1.25"`<br>`divValueStr = "0.5"` | 戻り値: `"2.50"` | 元データの小数点以下桁数（この場合はF2）を正確に自動検知して追従し、除算結果がその桁数でフォーマットされること。 |
| **2** | 正常系 | `currentRawVal = "10"`<br>`divValueStr = "4"` | 戻り値: `"3"` | 元データが整数（小数点なし：F0）の場合にその表記を追従すること（2.5 から四捨五入され 3 に整形されること）。 |
| **3** | 異常系（0除算） | `currentRawVal = "10"`<br>`divValueStr = "0"` | 戻り値: `"10"`<br>エラーメッセージが返されること | 除算値に0が指定された場合、処理を行わずに元の値を返すこと（0除算によるクラッシュの防止）。 |
| **4** | 異常系 | `currentRawVal = "INVALID"`<br>`divValueStr = "2.0"` | 戻り値: `"INVALID"`<br>エラーメッセージが返されること | 元データが数値に変換できない不正な文字列の場合に、計算を行わず元の文字列を返すこと（数値パースエラーのガード）。 |
