# コマンドリファレンス：ParamGet

## 概要
`ParamGet` は、指定された別のコマンドマスタ（サブルーチンや外部マクロ等）が保持する変数（`PARAM`）群から、複数の指定キーの値をペア単位で動的に一括取得（インポート）し、現在の自分の変数プールへと安全に格納・転送するための制御系シーケンスコマンドです。
外部の共通マクロ（サブルーチン）が実行された結果の判定ステータスや、測定によって得られた最終データを、呼び出し元のメインマクロ側へと安全に回収（戻り値の受け取り）するマクロ構造化設計において使用します。

> 💡 **補足 / ⚠️ 注意**
> コピー処理を行う前に、参照先マクロ（外部）と格納先マクロ（自分自身）の双方に変数の存在チェック（`TryGetValue`）を実施します。存在しないキーが記述されていても、`NullReferenceException` によるエラーを完全に防止します。

---

## 💡 書式・パラメータ仕様

```csv
,SEQUENCE, [ステップキー], ParamGet, [参照元マクロ名], [自格納先変数1], [相手参照先変数1], [自格納先変数2], [相手参照先変数2]...
```

### パラメータ（引数）一覧

マクロスクリプトからは、最初の参照元マクロ名に続けて、任意の個数（可変長）だけ [自格納先変数] と [相手参照先変数] のペアを連続して指定できます。

| 引数位置 | 引数名 | 説明 | 指定方法 / 有効な入力値 |
| :--- | :--- | :--- | :--- |
| **引数1** | 参照元マクロ名 | 変数の値を吸い上げる対象のターゲットマクロ（`COMMAND`）の名前。<br>先頭に `@` を指定すると共通コマンド（`GENERAL`）を対象とし、`@` を付けない場合は現在の機器に対するマクロを対象とします。 | 固定文字列（例: `"Sub_Measure"`、`"@Common_Measure"`）※変数置換対応 |
| **引数2** | 自格納先変数1 | 取得した値を格納する、自分自身（現在実行中マクロ）の変数名。 | `PARAM` で定義されたキー名（例: `"V_DATA"`） |
| **引数3** | 相手参照先変数1 | 値が格納されている、相手側（参照元マクロ）の変数名。 | `PARAM` で定義されたキー名（例: `"RAW_DATA"`） |
| **引数4〜** | 可変長引数ペア | 任意の個数（可変長）だけペアを並べて一括取得可能。 | 引数2・引数3の規則に準じる |

---

## 🔄 特殊置換規約・分岐規約の適用

本コマンドの引数における、独自スクリプトの特殊記法の適用ルールです。

*   **共通コマンド指定（`@`）**: 参照元マクロ名の先頭に `@` を付与することで、自身が属する機器（デバイス）に関わらず、共通コマンド（`GENERAL`）として定義されているマクロのパラメータを対象とすることができます。`@` を付けない場合は、現在の機器に対するマクロが対象となります。（例：`"@Sub_Measure"`）
*   **動的置換（`$`）**: すべての引数において、`$PARAMキー$` のようにパラメータキーの両端を `$` で囲むことで、実行時に変数プール（`PARAM`）の値へと動的にパース展開・値置換されます。
*   **条件ジャンプ（`#`）**: 本コマンドはジャンプ処理を行わないため、引数内での `#` によるステップキー指定は使用しません。
*   **カンマのエスケープ**: 可変長パラメータの各境界となるカンマと区別するため、参照元マクロ名等にカンマを含む文字列を指定する場合は、必ず `","` と二重引用符で囲んで記述する必要があります。

## 💡 動作例（正しい構文での記述例）

### スクリプト記述例
> ⚠️ **記述ルール注意**
> COMMANDブロック配下のため、子要素行（`PARAM`, `SEQUENCE`）は必ず行頭カンマから開始し、スペースインデントや行末コメント（`;`）は記述しないでください。コメントを入れる場合は、必ず独立したコメント行（行頭 `;`）を前に挟んでください。

```csv
# ======================================================================
# 呼び出される側のマクロ（共通モジュール：Sub_Measure）
# ======================================================================
COMMAND, "Sub_Measure"
,PARAM, RAW_DATA, Work, "生データバッファ", ""
,PARAM, ERR_CODE, Value, "エラーコード", "0"
; 測定を実行し、結果を自分の変数(RAW_DATA)と変数(ERR_CODE)に格納する
,SEQUENCE, 10, Send, "READ?"
# ======================================================================
# 呼び出す側のメインマクロ（戻り値回収フロー）
# ======================================================================
COMMAND, "Main_Process"
,PARAM, V_DATA, Work, "回収データ", ""
,PARAM, V_ERR, Value, "回収エラー", ""
; 1. サブルーチンを実行（この時点では相手側の変数プールにデータが格納される）
,SEQUENCE, 10, Call, "Sub_Measure"
; 2. 【一括取得】相手のデータ(RAW_DATA)を自分の(V_DATA)へ、相手のエラー(ERR_CODE)を自分の(V_ERR)へ回収
,SEQUENCE, 20, ParamGet, "Sub_Measure", "V_DATA", "RAW_DATA", "V_ERR", "ERR_CODE"
; 3. 回収したエラー値(V_ERR)を元に、以降の条件分岐（Judge等）へ安全に繋げる
,SEQUENCE, 30, Judge, EQU, V_ERR, 0, #50#
```

### 実行時の挙動・変数変化

*   **実行前の状態**: サブルーチン（`Sub_Measure`）の実行が完了し、相手側の変数プールに測定結果（`RAW_DATA`, `ERR_CODE`）が保持されている状態です。
*   **実行後の状態**: `ParamGet` コマンドにより戻り値が一括で回収されます。非破壊コピー処理のため、相手側の変数状態はそのまま維持され、自分自身の変数プールにある `V_DATA` および `V_ERR` へと安全に値が転送・上書き格納されます。

## 🚫 エラーハンドリング・安全設計（仕様制限）

入力データの異常や記述ミスに対し、解析・実行エンジンが実行するセーフティ規約です。

*   **参照元マクロ名（引数1）が見つからない場合**
    指定されたマクロ名がシステム内に登録されておらず、パラメータ辞書の取得に失敗した場合は、内部ログ（`_log.LogError`）を出力して値の取得処理を即座に安全にアボート（処理中断）します。
*   **引数のペアが不完全（奇数個）な場合**
    [自格納先] に対して [相手参照先] が不足している不完全な記述がある場合、端数の不完全ペアは自動的に無視（スキップ）され、型安全を最優先して処理を継続します。
*   **相手側に指定キーが存在しない場合**
    相手側マクロ内に指定された参照先変数キーが存在しない場合、ログにエラーを排出した上で該当する変数ペアの取得だけを安全にスキップし、残りのペア処理を続行します。
*   **自分自身に指定キーが存在しない場合**
    相手側からは値を取得できたものの、それを書き戻すべき自分自身の格納先変数キーが `Params` 辞書に存在しない場合、不正なメモリ書き込みを回避し、ログにエラーを出力してシステムを保護します。

## 🧪 ユニットテスト仕様

本コマンドクラスに実装されている `RunUnitTest()` メソッドが検証するユニットテストの仕様です。

### テスト実行前提条件
* **実行トリガー**: `RunUnitTest()` メソッドの呼び出し
* **有効化条件**: システム全体の最小ログレベル（`ErrorLogger.MinimumLevel`）が `LogLevel.Test` であること（それ以外の場合は無効化ガードにより即座に早期リターン）
* **検証結果出力**: `ErrorLogger.LogTest` によるログ出力。検証失敗時は `ErrorLogger.LogError`、予期せぬ例外発生時は `ErrorLogger.LogCritical` で記録

| :--- | :--- | :--- | :--- | :--- |
| **1** | 正常系 | `targetDict = { "@DEST1": "0" }`<br>`targetKey = "DEST1"`<br>`sourceDict = { "@SRC1": "transfer_value" }`<br>`sourceKey = "SRC1"` | 戻り値: `0`<br>`targetDict["@DEST1"]`の値が `"transfer_value"` に更新される | 存在する相手側の変数キーから値を取得し、自コマンドの存在する変数キーへ正しくコピー（転送）されること。 |
