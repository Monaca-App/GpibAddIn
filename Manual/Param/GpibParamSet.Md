# コマンドリファレンス：ParamSet

## 概要
`ParamSet` は、指定された別のコマンドマスタ（サブルーチンや外部マクロ等）が保持する変数（`PARAM`）群に対し、複数の指定キーと設定値をペア単位で動的に一括代入（セット）するための制御系シーケンスコマンドです [1.1]。
外部の共通マクロ（サブルーチン）を呼び出す前に、相手側の動作パラメータ（チャンネル番号、制限値、測定モードなど）を自由な組み合わせで一括で書き換える用途に活用されます [1.1]。

> ⚠️ **重要：引数の並び順に関する注意点**
> プログラム内の実装ループに基づき、記述するペアの順番は **`[設定する値] [対象変数キー]` の順** となります [1.1]。一般的な代入文（キー ＝ 値）とは左右逆の並び順になるため、記述の際は十分に注意してください [1.1]。

---

## 💡 書式・パラメータ仕様

```csv
,SEQUENCE, [ステップキー], ParamSet, [対象マクロ名], [設定する値1], [対象変数キー1], [設定する値2], [対象変数キー2]...
```

### パラメータ（引数）一覧

マクロスクリプトからは、最初の対象マクロ名に続けて、任意の個数（可変長）だけ [設定する値] と [対象変数キー] のペアを連続して指定できます [1.1]。

| 引数位置 | 引数名 | 説明 | 指定方法 / 有効な入力値 |
| :--- | :--- | :--- | :--- |
| **引数1** | 対象マクロ名 | 変数を上書きする対象のターゲットマクロ（`COMMAND`）の名前 [1.1]。<br>先頭に `@` を指定すると共通コマンド（`GENERAL`）を対象とし、`@` を付けない場合は現在の機器に対するマクロを対象とします。 | 固定文字列（例: `"Sub_Measure"`、`"@Common_Measure"`）※変数置換対応 [1.1] |
| **引数2** | 設定する値1 | 対象変数に代入したい文字列や数値 [1.1]。 | 固定値（例: `"AUTO"`）またはパラメータ動的置換（例: `$P_RANGE$`） [1.1] |
| **引数3** | 対象変数キー1 | 相手側（対象マクロ）に定義されている1つ目の変更先変数名 [1.1]。 | `PARAM` で定義されたキー名（例: `"RANGE"`）※変数置換対応 [1.1] |
| **引数4〜** | 可変長引数ペア | 任意の個数（可変長）だけペアを並べて一括代入可能 [1.1]。 | 引数2・引数3の規則に準じる [1.1] |

---

## 🔄 特殊置換規約・分岐規約の適用

本コマンドの引数における、独自スクリプトの特殊記法の適用ルールです。

*   **共通コマンド指定（`@`）**: 対象マクロ名の先頭に `@` を付与することで、自身が属する機器（デバイス）に関わらず、共通コマンド（`GENERAL`）として定義されているマクロのパラメータを対象とすることができます。`@` を付けない場合は、現在の機器に対するマクロが対象となります。（例：`"@Sub_Measure"`）
*   **動的置換（`$`）**: すべての引数において、`$PARAMキー$` のようにパラメータキーの両端を `$` で囲むことで、実行時に変数プール（`PARAM`）の値へと動的にパース展開・値置換されます [1.2]。これにより、自分自身の変数プールにある中身を、対象マクロ内の変数へ安全にコピー・代入（引き継ぎ）できます [1.2]。
*   **条件ジャンプ（`#`）**: 本コマンドはジャンプ処理を行わないため、引数内での `#` によるステップキー指定は使用しません [1.2]。
*   **カンマのエスケープ**: 可変長パラメータの各境界となるカンマと区別するため、設定する値等にカンマを含む文字列を指定する場合は、必ず `","` と二重引用符で囲んで記述する必要があります。

## 💡 動作例（正しい構文での記述例）

### スクリプト記述例
> ⚠️ **記述ルール注意**
> COMMANDブロック配下のため、子要素行（`PARAM`, `SEQUENCE`）は必ず行頭カンマから開始し、スペースインデントや行末コメント（`;`）は記述しないでください [1.2]。コメントを入れる場合は、必ず独立したコメント行（行頭 `;`）を前に挟んでください [1.2]。

```csv
# ======================================================================
# 呼び出される側のマクロ（共通モジュール：Sub_Measure）
# ======================================================================
COMMAND, "Sub_Measure"
,PARAM, RANGE, List, "RANGE", "AUTO"
,PARAM, TIMEOUT, Value, "TIMEOUT", "5"
,SEQUENCE, 10, Send, "CONF:VOLT 1"
# ======================================================================
# 呼び出す側のメインマクロ（パラメータ事前セットフロー）
# ======================================================================
COMMAND, "Main_Process"
,PARAM, P_RANGE, List, "ユーザー選択レンジ", "10V"
; 1. 【一括代入】自分の選択レンジの中身($P_RANGE$))を相手の「RANGE」へ、固定値「10」を相手の「TIMEOUT」へセット
; ※ [設定値] [相手のキー] の順でペアを記述します
,SEQUENCE, 10, ParamSet, "Sub_Measure", "$P_RANGE$", "RANGE", "10", "TIMEOUT"
; 2. パラメータが安全に書き換わった状態で、サブルーチンを実行
,SEQUENCE, 20, Call, "Sub_Measure"
```

### 実行時の挙動・変数変化

*   **実行前の状態**: ターゲットとなる共通マクロ（`Sub_Measure`）の変数 `RANGE` が `"AUTO"`、`TIMEOUT` が `"5"` で保持されており、呼び出す側のマクロで代入元の変数 `P_RANGE`（値: `"10V"`）が準備されている状態です [1.2]。
*   **実行後の状態**: `ParamSet` コマンドにより、対象マクロの変数プール（`Params` 辞書）へ値が直接安全に上書きされます [1.1]。具象型 `GpibSequence` への完全安全キャストに加え、相互のキーに対する存在チェック（`TryGetValue`）を伴って演算されるため、`NullReferenceException` によるエラーを完全に防止し、相手側の `RANGE` が `"10V"`、`TIMEOUT` が `"10"` へと一斉同期上書きされます [1.1, 1.2]。

## 🚫 エラーハンドリング・安全設計（仕様制限）

入力データの異常や記述ミスに対し、解析・実行エンジンが実行するセーフティ規約です。

*   **対象マクロ名（引数1）が見つからない場合**
    指定されたマクロ名がシステム内に登録されておらず、パラメータ辞書の取得に失敗した場合は、内部ログ（`_log.LogError`）を出力して値の代入処理を即座に安全にアボート（処理中断）します [1.2]。
*   **引数のペアが不完全（奇数個）な場合**
    `[設定値]` に対して `[対象キー]` が不足している不完全な記述がある場合、端数の不完全ペアは自動的に無視（スキップ）され、型安全を最優先して処理を継続します [1.3]。
*   **相手側に指定キーが存在しない場合**
    ターゲットマクロ内に対象の変数キーが存在しない場合、不正なメモリへの上書きを回避するため、ログにエラーを出力した上で該当ペアのセットだけを安全にスキップし、残りのペア処理を続行します [1.3]。

## 🧪 ユニットテスト仕様

本コマンドクラスに実装されている `RunUnitTest()` メソッドが検証するユニットテストの仕様です。

### テスト実行前提条件
* **実行トリガー**: `RunUnitTest()` メソッドの呼び出し
* **有効化条件**: システム全体の最小ログレベル（`ErrorLogger.MinimumLevel`）が `LogLevel.Test` であること（それ以外の場合は無効化ガードにより即座に早期リターン）
* **検証結果出力**: `ErrorLogger.LogTest` によるログ出力。検証失敗時は `ErrorLogger.LogError`、予期せぬ例外発生時は `ErrorLogger.LogCritical` で記録

### テストケース一覧

| No | テストカテゴリ | テスト条件（入力値） | 期待される結果（出力値） | 検証の目的 / 観点 |
| :--- | :--- | :--- | :--- | :--- |
| **1** | 正常系 | `paramsDict = { "@VAL1": "0", "@VAL2": "init" }`<br>`key = "VAL1"`<br>`value = "100.0"` | 戻り値: `true`<br>`paramsDict["@VAL1"]`の値が `"100.0"` に更新される | 存在する対象の変数キーに対し、指定値が正しくセット（代入上書き）されること。 |
| **2** | 異常系 | `paramsDict = { "@VAL1": "0", "@VAL2": "init" }`<br>`key = "NON_EXISTENT"`<br>`value = "999"` | 戻り値: `false`<br>`paramsDict`内のデータは変化しない | 存在しない変数キーが指定された場合にセット処理が失敗し、辞書内のデータが変更されないこと（早期ガードの検証）。 |
