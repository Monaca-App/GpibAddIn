# コマンドリファレンス：Replace

## 概要
Replace は、変数やパラメータ内の指定文字列を正規表現パターンで一括置換する文字列操作系コマンドです。測定データの整形や、可変長受信バッファから特定のインジケーター情報を抽出・削除する際など、システム内での高度な文字列パース処理に用いられます。

## 💡 書式・パラメータ仕様
```text
,SEQUENCE, [ステップキー], Replace, [置換対象のテキスト], [検索正規表現パターン], [置換後の文字列]
```

### パラメータ（引数）一覧

| 引数位置 | 引数名 | 説明 | 指定方法 / 有効な入力値 |
| :--- | :--- | :--- | :--- |
| 引数1 | 置換対象のテキスト | 置換処理を施す元の文字列またはバッファのキーを指定。 | 固定値 / PARAM変数キー / 動的置換（\$）可能 |
| 引数2 | 検索正規表現パターン | 検索対象となる正規表現文字列を指定。 | 固定値 / PARAM変数キー / 動的置換（\$）可能 |
| 引数3 | 置換後の文字列 | マッチした箇所に新しく挿入する文字列を指定。 | 固定値 / PARAM変数キー / 動的置換（\$）可能 |

## 🔄 特殊置換規約・分岐規約の適用
本コマンドの引数における、独自スクリプトの特殊記法の適用ルールです。
* **動的置換（\$）**: 引数内で `$PARAMキー$` のように記述すると、実行時に変数プール（PARAM）の値へ動的置換されます。（適用可能な引数：引数1、引数2、引数3のすべて）
* **条件ジャンプ（#）**: 本コマンドはシーケンス制御を行わないため、条件ジャンプは適用されません。（適用可能な引数：なし）
* **カンマのエスケープ**: 引数自体にカンマを含める場合は、必ず `","` と二重引用符で囲んで記述します。

## 💡 動作例（正しい構文での記述例）
```text
COMMAND, "RegexReplaceSample", "ResultBuffer"
; コメントは独立した行に記述（行末は完全禁止）
,PARAM, SrcData, Text, "受信生データ", "ID:1234_VAL:55.6A"
,PARAM, Pattern, Text, "抽出パターン", "[A-Z]"
,PARAM, ReplaceText, Text, "置換文字", ""
,SEQUENCE, STEP_001, Replace, SrcData , Pattern, ReplaceText
```

### 実行時の挙動・変数変化
* **実行前の状態**: 変数プール `SrcData` に `"ID:1234_VAL:55.6A"` が格納されており、`STEP_001` が開始されます。
* **実行後の状態**: 正規表現パターン `[A-Z]` にマッチした文字（I, D, V, A, L, A）がすべて空文字へ置換されます。結果として変数プール `SrcData` の値が `"1234_55.6"` へと書き換わります。

## 🚫 エラーハンドリング・安全設計（仕様制限）
入力データの異常や記述ミスに対し、解析・実行エンジンが実行するセーフティ規約です。
* **存在しない変数キーの指定（引数1）**: 指定されたキーがパラメータ空間（`param.Cmd.Params`）に見つからない場合、エンジンは `TryGetValue` によるガードを適用して処理をスキップし早期リターンを実行します。これにより `NullReferenceException` によるシステム強制終了を自動防御します。
* **不正な正規表現パターンの入力（引数2）**: 構文の壊れた正規表現パターンが指定され、実行時に内部で例外が発生した場合は、エンジンが `catch (Exception ex)` で例外を完全に捕捉します。コアエンジンを大クラッシュさせずにエラーログへ安全に隔離・記録し、システムの動作継続を担保します。

## 🧪 ユニットテスト仕様

本コマンドクラスに実装されている `RunUnitTest()` メソッドが検証するユニットテストの仕様です。

### テスト実行前提条件
* **実行トリガー**: `RunUnitTest()` メソッドの呼び出し
* **有効化条件**: システム全体の最小ログレベル（`ErrorLogger.MinimumLevel`）が `LogLevel.Test` であること（それ以外の場合は無効化ガードにより即座に早期リターン）
* **検証結果出力**: `ErrorLogger.LogTest` によるログ出力。検証失敗時は `ErrorLogger.LogError`、予期せぬ例外発生時は `ErrorLogger.LogCritical` で記録

### テストケース一覧

| No | テストカテゴリ | テスト条件（入力値） | 期待される結果（出力値） | 検証の目的 / 観点 |
| :--- | :--- | :--- | :--- | :--- |
| **1** | 正常系 | `sourceText = "VAL:12.34"`<br>`searchPattern = "VAL:(.*)"`<br>`replacementText = "$1"` | 戻り値: `"12.34"` | 正しい正規表現と置換指定子により、元の文字列から特定部分が正しく抽出・置換されること。 |
| **2** | 特殊系 | `sourceText = "VAL:12.34"`<br>`searchPattern = "NOTFOUND"`<br>`replacementText = "NEW"` | 戻り値: `"VAL:12.34"`（変化なし） | 正規表現パターンが一致しない場合、文字列に変化がないこと（非変更動作の確認）。 |
| **3** | 異常系 | `sourceText = "VAL:12.34"`<br>`searchPattern = "[A-Z"`（不正な正規表現）<br>`replacementText = "NEW"` | `ArgumentException` がスローされること | 括弧の閉じ忘れなどの不正な正規表現パターンが指定された場合に、適切に例外が検出されてスローされること。 |
