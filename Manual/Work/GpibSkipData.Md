# コマンドリファレンス：SkipData

## 概要
`SkipData` は、現在受信バッファ（`RecData`）内に保持されている文字列から、指定された `sscanf` 書式に基づいて不要なプレフィックスやヘッダー部分を読み飛ばし（スキップ）、以降のデータパース処理のために有効なデータのみを前詰めにクリーンアップするデータ前処理系シーケンスコマンドです [1.1]。
計測器から返されるデータに `"VOLT=1.234"` や `"CH1:+05.67"` のようなヘッダーや識別文字列が必ず付与されてしまう場合、後続の `Judge` コマンド（数値変換が必要な大小比較）や `Array_Set` へ渡す前に、不要なテキスト部分を1ステップで安全に分離（剥離）するために使用します [1.1]。

> 💡 **補足 / ⚠️ 注意**
> 本コマンドは、解析パラメータ（`AnaParam`）内の共通受信バッファである `param.RecData` の中身を直接書き換える「インプレース（破壊的）クリーンアップ」を行います [1.1]。指定された `sscanf` フォーマットとマッチングを行い、抽出された有効なデータ文字列で `param.RecData` を上書きします [1.1]。

---

## 💡 書式・パラメータ仕様

```csv
,SEQUENCE, [ステップキー], SkipData, [sscanf読み飛ばし書式]
```

### パラメータ（引数）一覧

| 引数位置 | 引数名 | 説明 | 指定方法 / 有効な入力値 |
| :--- | :--- | :--- | :--- |
| **引数1** | sscanf読み飛ばし書式 | プレフィックスを除外して残したい有効データを指定するパターン。省略時は `"%s"` [1.1]。 | 例: `"DATA:%s"`（`"DATA:"` を読み飛ばす）。 [1.1] |

---

## 🔄 特殊置換規約・分岐規約の適用

本コマンドの引数における、独自スクリプトの特殊記法の適用ルールです。

*   **動的置換（`$`）**: 引数1において、`$PARAMキー$` のようにパラメータキーの両端を `$` で囲むことで、実行時に変数プール（`PARAM`）の値へと動的にパース展開・値置換されます。
*   **条件ジャンプ（`#`）**: 本コマンドはジャンプ処理を行わないため、引数内での `#` によるステップキー指定は使用しません [1.2]。
*   **カンマのエスケープ**: 読み飛ばし書式文字列自体にカンマを含める場合は、構文エラーを防ぐため必ず `","` と二重引用符で囲んで記述する必要があります。

## 💡 動作例（正しい構文での記述例）

### データ前詰めの具体例と内部挙動
*   **初期の受信バッファ（`param.RecData`）の状態**: `"ERROR_CODE=004"` [1.1]
*   **マクロの記述**: `,SEQUENCE, 30, SkipData, "ERROR_CODE=%s"` [1.1]
*   **内部での書き換え処理**:
    1.  `objLib.sscanf("ERROR_CODE=004", "ERROR_CODE=%s")` が実行されます [1.2]。
    2.  プレフィックス `"ERROR_CODE="` が正常にスキップ（読み飛ばし）され、有効文字列 `"004"` が抽出されます [1.2]。
    3.  受信バッファ（`param.RecData`）の内容が、前詰めされた `"004"` へと上書き更新されます [1.2]。

### スクリプト記述例
> ⚠️ **記述ルール注意**
> COMMANDブロック配下のため、子要素行（`PARAM`, `SEQUENCE`）は必ず行頭カンマから開始し、スペースインデントや行末コメント（`;`）は記述しないでください [1.1, 1.2]。コメントを入れる場合は、必ず独立したコメント行（行頭 `;`）を前に挟んでください [1.2]。

```csv
COMMAND, "Direct_Buffer_Judge_Flow"
; コメントは独立した行に記述（行末への記述は完全禁止）
; 1. 測定クエリを送信し、生データを共通受信バッファへ回収
; ※バッファ（param.RecData）の中身が「VAL:+12.345」になると仮定
,SEQUENCE, 10, Send, "FETCH?"
,SEQUENCE, 20, Receive
; 2. 【バッファ前詰め】「VAL:」の部分を読み飛ばし、バッファを「+12.345」に前詰め更新
,SEQUENCE, 30, SkipData, "VAL:%s"
; 3. クリーンになった共通バッファ（引数2に「0」または空文字指定でRecDataを参照）と
; 上限閾値（15.0）を Judge コマンドでダイアログを挟まずに直接大小比較
; ※「VAL:」が付いたままだと数値変換エラーになりますが、前詰めされているため安全に評価できます
,SEQUENCE, 40, Judge, LE, 0, 15.0, #60#
; 4. 判定NG（15.0を超えた）の場合のエラー処理
,SEQUENCE, 50, Send, "OUTPUT OFF"
,SEQUENCE, 55, Exit
; 5. 判定OKの場合の正常終了
,SEQUENCE, 60, Exit
```

### 実行時の挙動・変数変化

*   **実行前の状態**: 測定コマンドによってデータが受信され、共通受信バッファにヘッダー付きの生データ文字列（例: `"VAL:+12.345"`)が保持されているコンテキストです [1.2]。
*   **実行後の状態**: 指定された書式に基づいてマッチングが行われ、前詰めされた有効文字列（例: `"+12.345"`)へとインプレース更新されます [1.1, 1.2]。後続の受信解析コマンド（`Judge` など）はヘッダーの存在を意識することなく、純粋な数値データとして安全にバッファを評価できるようになります [1.1, 1.2]。また、引数が省略された場合は、自動的に汎用読み取り書式である `"%s"`（文字列全体をそのまま維持）へと内部で自動フォールバックされます [1.1]。

## 🚫 エラーハンドリング・安全設計（仕様制限）

入力データの異常や記述ミスに対し、解析・実行エンジンが実行するセーフティ規約です [1.2]。

*   **受信バッファ（RecData）が元から空である場合の即時離脱**
    計測器からの応答がタイムアウトなどでそもそも空文字列（`string.IsNullOrEmpty`）であった場合、実行エンジンは無駄な `sscanf` パースを行わずに安全に処理をスキップ（早期リターン）します [1.2]。
*   **パース結果が不正（Null）だった場合の安全保護**
    万が一 `sscanf` の内部処理結果として `null` が返却された場合、バッファ構造を破壊させないよう、C# の null 合流演算子（`??`）を用いて安全な空文字（`string.Empty`）へと自動置換して格納します [1.3]。
*   **パース時にシステム例外が発生した場合（LogCritical）**
    外部文字列制御ライブラリのパースロジック内で予期せぬ内部システム例外が発生した場合でも、`catch (Exception)` ブロックがすべての例外を確実に捕捉します [1.3]。詳細なスタックトレースをログに完全保存（`LogCritical`）し、アプリケーション全体の強制終了を自動防御します [1.3]。

## 🧪 ユニットテスト仕様

本コマンドクラスに実装されている `RunUnitTest()` メソッドが検証するユニットテストの仕様です。

### テスト実行前提条件
* **実行トリガー**: `RunUnitTest()` メソッドの呼び出し
* **有効化条件**: システム全体の最小ログレベル（`ErrorLogger.MinimumLevel`）が `LogLevel.Test` であること（それ以外の場合は無効化ガードにより即座に早期リターン）
* **検証結果出力**: `ErrorLogger.LogTest` によるログ出力。検証失敗時は `ErrorLogger.LogError`、予期せぬ例外発生時は `ErrorLogger.LogCritical` で記録

### テストケース一覧

| No | テストカテゴリ | テスト条件（入力値） | 期待される結果（出力値） | 検証の目的 / 観点 |
| :--- | :--- | :--- | :--- | :--- |
| **1** | 正常系 | `recData = "HEADER:123.45"`<br>`format = "HEADER:%s"` | 戻り値: `"123.45"` | 指定されたプレフィックス部がスキップされ、それ以降の有効なデータ文字列のみが正しく前詰め抽出されること。 |
| **2** | 正常系 | `recData = "123.45"`<br>`format = "%s"` | 戻り値: `"123.45"` | プレフィックスなしの書式（`%s`）が指定された場合に、元の文字列全体がそのまま維持されて返されること。 |
| **3** | 異常系 | `recData = ""`（空文字列）<br>`format = "HEADER:%s"` | 戻り値: `""`（空文字列） | 受信バッファの元データが空（未受信）の場合に、パースを行わずに空文字列が安全に返されること。 |
