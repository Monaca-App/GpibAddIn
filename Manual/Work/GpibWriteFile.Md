# コマンドリファレンス：WriteFile

## 概要
`WriteFile` は、シーケンス実行中の指定データ（計測結果やステータス文字列など）を、指定された外部テキストファイルへ新規保存（上書き）または追記（Add）して動的にファイルエクスポートするためのファイルI/O系シーケンスコマンドです [1.1]。
常時ストリームを開き続ける `LogOut` コマンドとは異なり、実行された瞬間にピンポイントでファイルをオープン、書き込み、即座にクローズする「アドホック（都度）書き込み」を行います [1.1]。

> 💡 **補足 / ⚠️ 注意**
> 本コマンドは、現在のカレントディレクトリをアプリケーション実行フォルダへ自動補正した上で、指定データをファイルに安全に書き出します [1.1]。内部処理でデータを一端 UTF-8 のバイト配列へ展開し、下層I/Oレベルで書き込むため、文字化けを防止します [1.1]。

---

## 💡 書式・パラメータ仕様

```csv
,SEQUENCE, [ステップキー], WriteFile, [ファイル名], [書き込むデータ文字列], [出力モード]
```

### パラメータ（引数）一覧

| 引数位置 | 引数名 | 説明 | 指定方法 / 有効な入力値 |
| :--- | :--- | :--- | :--- |
| **引数1** | ファイル名 | 出力先ファイルの絶対パスまたは相対パス。（必須引数） [1.1] | 固定文字列、またはパラメータ動的置換（例: `$P_PATH$`） [1.1, 1.2] |
| **引数2** | 書き込むデータ文字列 | ファイルに書き出したい文字列データ [1.1]。 | 固定値、またはパラメータ動的置換（例: `$P_BUF$`） [1.1, 1.2] |
| **引数3** | 出力モード | 同名ファイル存在時の上書き/追記モードの指定 [1.1]。 | `New`（上書き）、`Add`（追記）、`Cancel`（中断） ※省略時は確認ダイアログを表示 [1.1] |

---

## 🔄 特殊置換規約・分岐規約の適用

本コマンドの引数における、独自スクリプトの特殊記法の適用ルールです。

*   **動的置換（`$`）**: 引数1（ファイル名）および引数2（書き込むデータ）の双方において、`$PARAMキー$` のようにパラメータキーの両端を `$` で囲むことで、実行時に変数プール（`PARAM`）の値へと動的にパース展開・値置換されます [1.2]。これにより、型番や測定データをパスやデータ部として動的に組み込み、即座に保存することが可能です [1.2]。
*   **条件ジャンプ（`#`）**: 本コマンドはジャンプ処理を行わないため、引数内での `#` によるステップキー指定は使用しません [1.2]。
*   **カンマのエスケープ**: 書き込むデータ文字列自体にカンマを含める場合は、構文エラーを防ぐため必ず `","` と二重引用符で囲んで記述する必要があります。

## 💡 動作例（正しい構文での記述例）

### スクリプト記述例
> ⚠️ **記述ルール注意**
> COMMANDブロック配下のため、子要素行（`PARAM`, `SEQUENCE`）は必ず行頭カンマから開始し、スペースインデントや行末コメント（`;`）は記述しないでください [1.1, 1.2]。コメントを入れる場合は、必ず独立したコメント行（行頭 `;`）を前に挟んでください [1.2]。

```csv
COMMAND, "Export_Data_Flow"
; コメントは独立した行に記述（行末への記述は完全禁止）
,PARAM, P_PATH, Text, "出力ファイル名", "C:\Data\today_measure.txt"
,PARAM, P_BUF, Work, "データバッファ", ""
; 1. 測定コマンド送信と受信を繰り返しバッファ(P_BUF)へ行蓄積（処理省略）
,SEQUENCE, 10, Send, "FETCH?"
,SEQUENCE, 20, SetData_RowAdd, P_BUF, "%s"
; 2. 【ピンポイント外部出力】蓄積されたバッファ(P_BUF)の中身を即座にファイル(P_PATH)へ新規書き出し
; ※引数3に「New」を指定しているため、同名ファイルがあってもダイアログを出さず自動で上書き初期化します
,SEQUENCE, 30, WriteFile, $P_PATH$, $P_BUF$, "New"
; 3. 回線をクローズして正常終了
,SEQUENCE, 40, Close
```

### 実行時の挙動・変数変化

*   **実行前の状態**: 測定シーケンスが完了し、変数プール内のバッファ（例: `P_BUF`）に蓄積されたデータを、指定されたファイルパス（例: `P_PATH`）へ即座にエクスポートしたいコンテキストです [1.2]。
*   **実行後の状態**: 指定されたファイル名とデータが評価され、該当ファイルがピンポイントでオープン・書き込み・即座にクローズされます [1.1]。引数3に出力モード（`New`/`Add`）が省略されている状態で同名ファイルが既に存在する場合は、安全な確認ダイアログ（`MessageBox`）を最前面にポップアップ生成し、作業者の選択（上書き/追記/キャンセル）に応じて動作を柔軟にマージします [1.1]。

## 🚫 エラーハンドリング・安全設計（仕様制限）

入力データの異常や記述ミスに対し、解析・実行エンジンが実行するセーフティ規約です [1.2]。

*   **ファイル名（引数1）の未指定ガード（エラーログ）**
    引数1が省略されている、または完全な空文字スペース（`string.IsNullOrWhiteSpace`）であった場合は、ファイルシステム保護のため内部ログ（`_log.LogError`）を出力し、書き込みを行わずに安全に早期リターン（処理スキップ）します [1.2]。
*   **出力モードで「Cancel」が選択・パースされた場合**
    引数3で明示的に `"Cancel"` が指定された場合、またはポップアップダイアログで作業者が `[キャンセル]` を選択した場合は、ファイルに一切触れることなく即座に処理を中断・離脱します [1.2]。
*   **確認ダイアログのUIスレッド安全ガード**
    モードが省略され、かつ既存ファイルが存在する場合に起動する `MessageBox` 表示は、内部で自動的に `targetForm.InvokeRequired` を判定します [1.2]。バックグラウンドの測定スレッドを巻き込んで画面のフリーズが発生するのを防止するため、必ずメインUIスレッド側へ同期（`Invoke`）させて最前面表示を制御します [1.2, 1.3]。
*   **物理I/O処理時にシステム例外が発生した場合（LogCritical）**
    フォルダ書き込み権限エラーやディスク満杯など、I/O処理最下層で予期せぬ例外が発生した場合、`catch (Exception)` ブロックがすべての例外を確実に捕捉します [1.3]。スタックトレースをログに完全保存（`LogCritical`）し、アプリケーション全体の強制終了を自動防御します [1.3]。

## 🧪 ユニットテスト仕様

本コマンドクラスに実装されている `RunUnitTest()` メソッドが検証するユニットテストの仕様です。

### テスト実行前提条件
* **実行トリガー**: `RunUnitTest()` メソッドの呼び出し
* **有効化条件**: システム全体の最小ログレベル（`ErrorLogger.MinimumLevel`）が `LogLevel.Test` であること（それ以外の場合は無効化ガードにより即座に早期リターン）
* **検証結果出力**: `ErrorLogger.LogTest` によるログ出力。検証失敗時は `ErrorLogger.LogError`、予期せぬ例外発生時は `ErrorLogger.LogCritical` で記録。テスト完了時およびクリーンアップ時には、検証用の一時ファイル（`test_write_file_temp.txt`）を自動的に削除します。

### テストケース一覧

| No | テストカテゴリ | テスト条件（入力値） | 期待される結果（出力値） | 検証の目的 / 観点 |
| :--- | :--- | :--- | :--- | :--- |
| **1** | 正常系 | `fileName = "test_write_file_temp.txt"`<br>`data = "Hello "`<br>`append = false` | ファイルが新規作成され、ファイルの内容が `"Hello "` と一致する。 | `WriteFile` メソッドによる新規ファイル作成および指定データの書き込み（上書き）動作の検証。 |
| **2** | 正常系 | `fileName = "test_write_file_temp.txt"`（既存）<br>`data = "World!"`<br>`append = true` | 既存ファイルにデータが追記され、ファイル全体のデータが `"Hello World!"` と一致する。 | `WriteFile` メソッドの追記モード（`append = true`）による、既存ファイル末尾への文字列追記動作の検証。 |
