# コマンドリファレンス：SendFile

## 概要
`SendFile` は、シーケンス実行中に外部のテキストファイルから自動計測マクロやスクリプトを読み込み、「別の入れ子（ネスト）シーケンス」として一括読み込み・非同期実行させるためのファイル連携型・フロー制御系シーケンスコマンドです [1.1]。
マクロファイルの部品化（モジュール化）を実現するとともに、送信に使用したスクリプトファイルのパスをメイン画面の履歴メニュー（`MruList`）へ動的に追加・並び替え制御する高度なUI同期管理機能を備えています [1.1]。

> 💡 **補足 / ⚠️ 注意**
> 本コマンドによって正常にファイルが読み込まれると、メイン画面の「送信テキスト（`strSendText`）」ドロップダウンメニューに対して、以下の最新MRU履歴管理がスレッド安全（`BeginInvoke`）に自動適用されます [1.2]。
> 1. **重複の自動パージ**: 過去に同じファイルパスが登録されていた場合、メニュー内を全検索して古い項目を一旦削除します [1.2]。
> 2. **最上位への挿入**: 読み込まれた最新のファイルパス（`ToolStripMenuItem`）を、常に履歴リストの最先頭（インデックス0番）へと動的にインサートします [1.2]。
> 3. **最大履歴数のクリッピング**: 登録可能な最大履歴数は10件に厳格に制限されており、これを超えた古い履歴アイテムは自動的にメモリ上から破棄（`Dispose`）および削除（`RemoveAt`）され、リソースリークを防ぎます [1.2]。
> 4. **履歴クリック時の自律実行**: 画面上の履歴メニューをクリックすると、二重クリック防止のロック（`SetSendMenuEnabled = false`）を自動適用しながら、該当ファイルを非同期で最速再実行します [1.2]。

## 💡 書式・パラメータ仕様

```csv
,SEQUENCE, [ステップキー], SendFile, [読み込み先マクロファイルパス]
```

### パラメータ（引数）一覧

| 引数位置 | 引数名 | 説明 | 指定方法 / 有効な入力値 |
| :--- | :--- | :--- | :--- |
| **引数1** | マクロファイルパス | 読み込んで実行させる外部スクリプトファイル（.txt等）の絶対パスまたは相対パス [1.1]。 | 固定パス、またはパラメータ動的置換（例: `$P_FOLDER$`） [1.1] |

---

## 🔄 特殊置換規約・分岐規約の適用

本コマンドの引数における、独自スクリプトの特殊記法の適用ルールです [1.1]。

*   **動的置換（`$`）**: 引数1のパス文字列内において、`$PARAMキー$` のようにパラメータキーの両端を `$` で囲むことで、実行時に変数プール（`PARAM`）の値へと動的にパース展開・値置換されます（例: `"C:\Macro\$P_FOLDER$\test.txt"`） [1.1, 1.2]。試験する製品の型番やロット番号などに基づいて、読み込む試験マクロファイルを動的に切り替えるインテリジェントな条件切り替えが実装できます [1.1]。
*   **条件ジャンプ（`#`）**: 本コマンドはジャンプ処理を行わないため、引数内での `#` によるステップキー指定は使用しません [1.2]。
*   **カンマのエスケープ**: ファイルパス文字列自体にカンマを含める場合は、構文エラーを防ぐため必ず `","` と二重引用符で囲んで記述する必要があります。

## 💡 動作例（正しい構文での記述例）

### スクリプト記述例
> ⚠️ **記述ルール注意**
> COMMANDブロック配下のため、子要素行（`PARAM`, `SEQUENCE`）は必ず行頭カンマから開始し、スペースインデントや行末コメント（`;`）は記述しないでください [1.1, 1.2]。コメントを入れる場合は、必ず独立したコメント行（行頭 `;`）を前に挟んでください [1.2]。

```csv
COMMAND, "Master_Sequence_Run"
; コメントは独立した行に記述（行末への記述は完全禁止）
,PARAM, P_FOLDER, Text, "品種フォルダ名", "HP_3458A_SPEC"
; 1. 全体回線のオープンと初期設定
,SEQUENCE, 10, Open
,SEQUENCE, 20, Init
; 2. 【外部ファイルネスト実行】品種に応じた詳細測定スクリプトを外部から呼び出す
; ※送信中はキャンセル画面が最前面にポップアップします
,SEQUENCE, 30, SendFile, "C:\GPIB_Macros\$P_FOLDER$\measure_profile.txt"
; 3. 後始末と切断
,SEQUENCE, 40, Close
```

### 実行時の挙動・変数変化

*   **実行前の状態**: メインシーケンスの初期化が完了し、特定の製品品種に応じた外部サマクロファイル（例: `P_FOLDER` = `"HP_3458A_SPEC"`）をロードして動的にネスト実行したいコンテキストです [1.2]。
*   **実行後の状態**: 外部ファイルの読み込みに先立ち、アプリケーションの実行ディレクトリ（`Assembly.GetExecutingAssembly().Location`）をカレントに強制セットすることで、相対パスによる記述ブレや読み込みミスを根本から防ぎます [1.1]。ファイル全体の読み込み（`File.ReadAllLines`）は `Task.Run` によって非同期スレッドへ委譲されるため、巨大なサブマクロファイルを読み込んだ場合でも画面がフリーズしません [1.1]。また、送信開始と同時に進捗・キャンセル用のサブフォーム（`GpibCancelForm`）が最前面に起動し、作業者がキャンセルボタン（`IsCancelled`）を押すことで安全に中途離脱できます [1.1]。

## 🚫 エラーハンドリング・安全設計（仕様制限）

入力データの異常や記述ミスに対し、解析・実行エンジンが実行するセーフティ規約です [1.2]。

*   **ファイル欠損時のエラーガード（マクロ安全着陸）**
    指定パスにファイルが存在しない場合（`File.Exists == false`）、内部ログ（`_log.LogError`）を出力した上で、作業者へエラーメッセージボックス（最前面 `MessageBox.Show`）をポップアップ提示します [1.3]。その後、親マクロをクラッシュさせずに `param.Jump = true` とし、遷移先をマクロの最終端（`Sequences.Count`）へ強制設定して、安全に処理を早期離脱させます [1.3]。
*   **致命的例外が発生した場合（LogCritical）**
    履歴メニューへのバインド時や `GpibCancelForm` の描画破棄（`Dispose`）の最中に予期せぬスレッド例外が発生した場合、`catch (Exception)` ブロックがすべての例外を確実に捕捉します [1.3]。詳細なスタックトレースをログに完全保存（`LogCritical`）し、エディタUIや測定スレッド全体の強制終了を自動防御します [1.3]。

## 🧪 ユニットテスト仕様

本コマンドクラスに実装されている `RunUnitTest()` メソッドが検証するユニットテストの仕様です。

### テスト実行前提条件
* **実行トリガー**: `RunUnitTest()` メソッドの呼び出し
* **有効化条件**: システム全体の最小ログレベル（`ErrorLogger.MinimumLevel`）が `LogLevel.Test` であること（それ以外の場合は無効化ガードにより即座に早期リターン）
* **検証結果出力**: `ErrorLogger.LogTest` によるログ出力。検証失敗時は `ErrorLogger.LogError`、予期せぬ例外発生時は `ErrorLogger.LogCritical` で記録
